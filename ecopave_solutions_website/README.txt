# EcoPave Solutions Website

A responsive static website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — website structure and content
- `style.css` — responsive visual design
- `script.js` — mobile navigation, year and enquiry form interaction
- `assets/` — supplied EcoPave logo, letterhead and promotional images

## Run locally
1. Extract the ZIP file.
2. Open the `ecopave_solutions_website` folder.
3. Double-click `index.html` to open it in a browser.

For local development, you can also open the folder in VS Code and use the Live Server extension.

## Enquiry form
The form uses a `mailto:` link to prepare an email addressed to `info@ecopavesolutions.in`. It does not store or transmit enquiries to a server. A working server-side form or form service must be connected before launch if you want online submissions.

## Before publishing
- Confirm that the email address and domain are registered and active.
- Confirm that the displayed address is the actual business contact address.
- Add real product specifications, photographs, certifications and project images only after verification.
- Upload the complete folder to a hosting provider. The website domain is not automatically registered by this project.
